## 用户要求和视觉方向

用户希望以组件预览页的浅色、深色玻璃效果为基准改造文件管理器。参考实现位于 `applications/component_gallery/main.cpp`，仓库已有 `docs/screenshots/forma-components-light.png`、`forma-components-dark.png` 和 `forma-components-overflow.png` 可供对照；这些截图是参考效果，不代表当前 Finder 的最新效果。

用户持续指出的具体问题是：白底玻璃发灰、显脏；胶囊和弹出菜单边框过厚或不自然；不同位置的菜单看起来不统一；减少脏感后又变成白色面板，磨砂透色太弱。最近一次反馈是菜单模糊“太薄，几乎看不见”。

目标是保留细亮边、背景透色和模糊轮廓，让菜单有玻璃感，同时保证前景文字清晰。不要用大幅增加白色遮罩来解决发灰，也不要只统一枚举参数就宣称所有场景已视觉一致。用户尤其关注三个点菜单、选中文件右键、空白处右键和子菜单。

## 当前玻璃实现

主要入口为 `src/theme/theme.cpp` 的 `Theme::material()`。Sidebar、Menu、Popover、Titlebar 和 Glass 共用表面参数，各区域主要调整模糊范围；Titlebar 作为连续表面不画外围边线，GlassClear 保留独立的清透映射。

| 参数 | 浅色 | 深色 |
| --- | --- | --- |
| saturation | 1.3 | 1.3 |
| noise | 0.003 | 0.003 |
| tint | white，alpha 0.04 | white，alpha 0.04 |
| border | black，alpha 0.09 | white，alpha 0.16 |
| bezelWidth | 12 | 12 |
| refraction | 8 | 8 |
| rimStrength | 0.32 | 0.22 |
| toneLow | 0.22 | 0.07 |
| toneHigh | 0.97 | 0.42 |

模糊半径：Glass 为 8，Menu 和 Popover 为 12，Sidebar 为 24，Titlebar 为 20，GlassClear 为 1.5，单位为逻辑点。

这些半径不是精确的高斯 sigma。`Renderer2D::blurScene()` 使用 dual Kawase 模糊，按半径和缩放计算下采样层数，并限制在 1 到 6 层；因此小范围修改参数可能完全不改变层数，跨越阈值又可能明显改变效果。不要以为参数数值翻倍就等同视觉模糊翻倍。

最新一轮将浅色 toneLow 从 0.50 降到 0.22，toneHigh 从 1.0 降到 0.97，并将菜单半径从 24 调回 12。原因是原来的强提亮和大范围模糊共同抹掉了白底文件列表的背景层次。最新版本侧重让背景模糊轮廓重新可见，而非继续增大半径。

### 投影和边缘

`shaders/ui.frag` 已移除原来宽范围的内阴影和肩部高光，改用窄的方向性亮边，减少白底灰圈。

`Painter::drawShadow()` 和 `Renderer2D::shadow()` 增加末尾可选参数 `exterior`，默认 false。玻璃组件使用以下顺序：

1. 绘制材质，采样尚未包含自身投影的背景。
2. 使用 `exterior=true` 绘制投影，着色器将面板内部挖空。
3. 绘制文字、图标和其他内容。

Popup、ToolbarGroup、玻璃 Button 和 SplitView 侧栏已接入该顺序。不要把它们改回先投影再采样材质，否则自身黑色阴影会进入模糊背景，使玻璃再次发灰。普通非玻璃控件保留原有投影行为。

### 菜单布局

`src/widgets/menu.cpp` 统一保留勾选列和图标列，测量与绘制都使用固定列宽，避免菜单是否存在 checked/icon 项改变文字起点。菜单内容数量不同，宽高和弹出位置仍可能不同。

Finder 中“文件右键”和“空白处右键”使用的是同一个 `MenuView` 实例。`applications/finder/main.cpp` 的 `browser->contextMenu` 只替换 `itemItems()` 或 `backgroundItems()`，并没有切换材质。三个点溢出菜单、普通菜单和子菜单最终均经 `MenuView`、`PopupView` 绘制。

透明材质仍会随底下的选中行、文字、图标和面板位置变化，这不等于使用了不同样式。排查时应同时比较材质、布局、采样内容和实际运行版本。

### 背景采样范围

当前模糊只采样窗口内已经绘制到 scene 的内容，不采样窗口外桌面壁纸。白色标题栏上的小菜单天然缺少彩色背景，不能指望它和组件预览页彩色条纹上的玻璃呈现相同透色。

Finder 列表 `ScrollView` 已从 Soft 改为 Hard 磨砂滚动边缘，入口在 `applications/finder/main.cpp`。共享材质变动会影响其他使用这些 Material 的 Forma 应用，调整后需留意组件预览页和应用商店。

## 接手后的优先事项

1. 先确认用户已安装并重启 `0.1.0-18`。最新效果尚未得到用户确认，不要把上一轮交付当作验收完成。
2. 若继续反馈菜单玻璃太弱或不统一，在同一个测试目录、相同缩放下，成组检查文件右键、空白处右键、三个点和子菜单，覆盖浅色与深色；保留调整前后的截图。
3. 同时检查背景层次、前景可读性、边框和投影。白底“更白”并不代表材质更干净，模糊半径“更大”也不代表玻璃感更明显。
4. 保留共享材质和固定菜单列宽的回归测试，避免重新出现角色间参数漂移或内容变化引起的布局跳动。
5. 若要发布新安装包，先完成构建、CTest 和截图验证，再递增 pkgrel 打包。对子模块的进一步修改，应单独验证其构建和系统交互。
